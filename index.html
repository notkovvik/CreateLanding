Как развернуть за 5 шагов

Ничего устанавливать не нужно. Только браузер, аккаунт GitHub и 5 минут времени.

  1. Сгенерируйте файл Заполните форму ниже, нажмите «Скачать index.html».
  2. Создайте репозиторий На GitHub создайте публичный репозиторий с именем <ваш-логин>.github.io.
  3. Загрузите файл В пустом репозитории нажмите «creating a new file», назовите его index.html и вставьте содержимое. Commit changes.
  4. Включите Pages Settings → Pages. Source: Deploy from a branch. Branch: main, папка / (root). Save.
  5. Откройте сайт Через 1–3 минуты сайт заработает по адресу https://<ваш-логин>.github.io/
